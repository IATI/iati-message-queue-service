Operations

  • RECEIVE iati-mq-registry-changes-sub-bds-test

    A subscription that receives notifications of changes to IATI Registry data (dataset and reporting_org) records are sent.

    The address above (iati-mq-registry-changes-sub-bds-test) is an Azure Service Bus subscription where notifications of changes to Registry records will be delivered. Messages received on this subscription come from the Service Bus topic iati-mq-registry-changes-topic-test.

    The general form of the subscription name is iati-mq-registry-changes-sub-bds-INSTANCE, where INSTANCE is to be replaced with one of test, dev, and prod, as per the typical IATI server setup. (Currently only test is active).

    The operation ID registry_changes is to uniquely identify operations, when a channel supports more than one. It does not need to appear anywhere in the message sent.

    Operation IDregistry_changes

    Available only on servers:

    • iati-mq-test-amqp
    • iati-mq-test-https

    Accepts one of the following messages:

    A topic to which the Bulk Data Service sends notifications of dataset download check operations, as well as the results of those operations.

    The Bulk Data Service dataset checks always involve issuing a HEAD request for the dataset, but only if needed will a GET request be made, so these dataset check records may indicate the dataset has been re-downloaded or may indicate that a HEAD request has confirmed the dataset is unchanged.

    The dataset_check_result property of the message payload is the complete Bulk Data Service record for the given dataset (as included in the Bulk Data Service's Full Index).
